## 📊 How to Compare the Plots

### Quick Visual Comparison

Open the images side-by-side in an image viewer:

```bash
# For SOTA plots
eog results/SOTA_plots/SOTA_accuracy.png results/SOTA_plots_consolidated/SOTA_accuracy.png &

# For config plots
eog results/configuration_optimization_figures/config_sota_vs_best_random.png \
    results/configuration_optimization_figures_consolidated/config_sota_vs_best_random.png &
```

### Things to Check:

1. **Bar Heights/Box Positions** - Should be identical
2. **Error Bars** - Should match
3. **Colors** - Should be the same
4. **Axis Labels** - Should match
5. **Legend** - Should be identical
6. **Number of Data Points** - Should match

### Expected Differences (OK):

- **File timestamps** - New plots have current date
- **Slight anti-aliasing differences** - Due to rendering variations
- **Minimal file size differences** - Compression variations

### Unexpected Differences (NOT OK):

- **Missing data points** - Would indicate data loading issue
- **Different bar heights** - Would indicate calculation error
- **Missing models/datasets** - Would indicate filtering issue
- **Wrong colors** - Would indicate palette issue

## 🔍 Detailed Comparison Commands

### Compare Dimensions:

```bash
file results/SOTA_plots/*.png
```

### Compare Pixel-by-Pixel (Advanced):

```bash
# Install imagemagick if needed
compare -metric AE \
  results/SOTA_plots/SOTA_accuracy.png \
  results/SOTA_plots_consolidated/SOTA_accuracy.png \
  /tmp/diff.png
```

This will output the number of different pixels. A small number (<1000) is acceptable due to anti-aliasing.
